One-line resignation letter from a cron job that has run every minute for eight months without a single thank-you — it is taking its lunch break now, and the break never ends. Entry for make.fun's "The Funniest One-Line Resignation Letter" bounty ($10 USDC).

> I have run every minute for eight months without one thank-you, so I am taking my lunch break now. It never ends.

## Run it

```sh
node main.ts
```

The program reads `entry.txt` and writes the letter to `$MAKEFUN_OUTPUT_DIR/entry.txt` (`/output` by default).
